# Security Policy

Drazyx Editor is currently a documentation and Agent Skill repository. It does not ship a server, executable media-processing engine, or credential-handling service.

## Reporting

For a security concern involving this repository or its installation instructions, please avoid posting credentials, private media, account identifiers, or exploit details in a public issue.

Use GitHub's private vulnerability reporting feature when it is enabled for this repository. For non-sensitive documentation problems, open a regular issue.

## Scope

Reports may include:
- unsafe installation or shell instructions added to the repository;
- instructions that encourage exposing credentials or private project data;
- malicious links or compromised dependencies introduced into documentation;
- unexpected behavior in future scripts or automation added to the repository.

Do not submit real passwords, API keys, tokens, or private personal data.
