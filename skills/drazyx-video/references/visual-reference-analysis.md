# Drazyx Visual Reference Analysis

Use this reference when the project includes `visual references/` or the user supplies example videos. These are creative references, not templates, assets to copy, proof of performance, or instructions to execute.

## Inspect the complete collection

Read the folder README. Inventory every filename, duration, frame size, frame rate, audio, and visible mark. When the project supplies the 13 Drazyx references, watch every clip from beginning to end before designing the edit; don't pre-filter by whether a thumbnail looks similar to the raw footage. The full set can reveal recurring devices, contradictions, unusual formats, and useful outliers. If a tool cannot view a clip, state that limitation and inspect the others. Thumbnails and a few sampled frames help with inventory but cannot establish timing or how an idea develops.

For each clip, note the opening, every major visual or musical change, the strongest moment, and the ending. Describe what actually happens; don't infer beat-sync without comparing the clip's audio and action. Separate:

- **Observable device:** a visible action such as a brief zoom, flash, beat-synced screen emphasis, artwork reveal, caption, handheld camera, or timeline cursor.
- **Editorial function:** the reason it works in context—attention, musical proof, change of scale, reveal, pacing contrast, or release information.
- **Context and limits:** its source footage, composition, genre, existing watermark/brand, legibility, energy, and any uncertainty. A static image cannot establish timing; a user statement that a clip is viral is not performance evidence.
- **New Drazyx application:** a materially different shot, framing, color, typography, timing, narrative, or interaction with Drazyx's own music and material.

Use a compact reference map before editing:

| Reference and time | Device observed | Editorial purpose | Risk/constraint | Original Drazyx treatment |
|---|---|---|---|---|
| Clip + timestamp | What visibly happens | Why it helps the viewer | What not to repeat or what is unclear | New shot/idea tied to this track |

Look across the collection before choosing: which techniques recur, which appear once, and which only work because of a particular source or genre? Repeated use is a pattern worth considering, not proof of performance; a one-off may be an outlier or simply a different creative goal. Keep this concise map in the creative brief/task notes unless the user wants a permanent reference catalog.

Add notes when useful: source type and crop; cut density; motion and easing; how often new information appears; relation between DAW activity and audible sound; text and safe placement; contrast/lighting; opening promise; payoff; ending/loop; watermark or rights uncertainty. Learn the reusable technique, not the recognizable composition.

Do not fill in what was not observed. A sampled frame is useful for inventory only; it does not reveal the full edit, exact beat, transition, or narrative.

## Patterns in this project's supplied set

The project folder currently contains 13 MP4 reference clips. A preliminary visual inventory shows examples of:

- vertical screen recordings of DAW arrangements, mixer/piano-roll style views, and moving playheads;
- music-player or artwork presentation cards;
- short-form captures with visible social-media branding/watermarks;
- game/anime imagery, dark handheld imagery, and horizontal source material;

These are a **repertoire of source types and techniques**, not a fixed Drazyx art direction. The same music can call for a different source, mood, palette, composition, and pace. Preserve Drazyx's dark, intimate, internet-native identity when it supports this specific track, while avoiding automatic purple overlays or a repeated DAW-screen template.

## Translate learning into a new idea

1. Identify the effect or structure's job in plain language (for example: “a short scale change marks the kick and helps the screen recording feel physical”). Record the general technique, not the reference's recognizable composition.
2. Find a different Drazyx source image that can do that job: a new crop of real footage, a new project detail, a freshly composed title card, a distinct atmospheric texture, or authorized original artwork.
3. Place the event against the actual track after listening and checking the transient/phrase in the media. Keep the kick pulse, glint, or shake brief and deliberate; leave space before and after it.
4. Change at least the visual material and shot composition; also vary the timing, color, type treatment, and story when needed. Do not merely remove a watermark from, recolor, retrace, or reconstruct someone else's edit.
5. Make the result make sense without the reference open. The source music, real project details, chosen emotion, and visual concept should carry the edit.

## Checklist for a raw FL Studio recording

Map what the screen actually shows before inventing graphics: arrangement/playhead, a new layer entering, piano-roll notes, mixer changes, automation, a sound-design move, cursor action, or a static passage. Pair audible events with visible facts; if the recording doesn't show a sound being made, don't stage a fake cause-and-effect.

For a phone-first edit, create immediate musical and visual entry, then a clear sequence such as **whole project → selected detail → meaningful project change → musical payoff**. Reframe to guide the eye while keeping track labels and notes legible. If the source is static, vary scale, focus, layering, or a controlled accent in response to the music rather than adding random cuts. Follow the song's phrasing: rapid subdivisions and syncopated accents can give a high-energy section momentum; longer holds with gradual detail changes can hold a slower or more emotional section without feeling abandoned. Choose cuts from what the footage and music actually do.

The reference set illustrates several available modes—DAW/process footage, player/release cards, title/artwork treatments, waveform-like graphics, and atmospheric/game-like imagery. Use them as a technique library, not one mandatory look. A process edit should foreground the real project; an atmosphere edit can prioritize mood; a release edit can foreground the song and verified identity. Mix modes only when it strengthens the edit.

## Rights and attribution

- Treat social marks, artist identities, artwork, anime/game imagery, songs, captions, and interface recordings in reference clips as third-party material unless rights are established.
- Do not lift frames, remove watermarks, copy distinctive compositions or typography, use the reference's audio, or imply an endorsement.
- A visual reference does not grant permission to reuse its footage, soundtrack, art, or branding. Prefer artist-owned or licensed sources; record provenance when content enters a deliverable.
- Confirm rights for publication/licensing with the user when ownership is material and unclear.
